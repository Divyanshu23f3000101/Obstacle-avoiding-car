The objective :-

This project is to design and build an autonomous obstacle-avoiding robot car using an HC-SR04 ultrasonic sensor mounted on an SG90 servo motor for dynamic environment scanning. The system detects physical barriers in real time and automatically re-routes the vehicle along a clear path.. The hardware integration ensures reliable power distribution and real-time motor control. Ultimately, this setup demonstrates a practical application of embedded C programming, sensor fusion, and automated path planning for mobile robotics.
